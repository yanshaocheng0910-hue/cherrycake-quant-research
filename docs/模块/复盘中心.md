# A 股复盘中心｜从当日事实到次日验收

[返回作品导览](../作品导览.md) · [工作台的盘后阶段](工作台.md#after) · [AI 在复盘中的作用](AI助手.md#review)

复盘中心把十个分页连成一条链：**复盘看板 → 盘面数据 → 首板分析 → 五日热度 → 涨停样本 → 连板天梯 → 情绪周期 → 明日验证 → 竞价核验 → 口径与证据**。前面的页面建立“今天发生了什么”，后面的页面负责写下“明天怎样检查”。日期、样本分母、来源和缺失状态随结果保留，而不是只留下一个市场温度分数。

<a id="dashboard"></a>
## 01 · 复盘看板

先选择复盘日期与统计窗口，再同时阅读上涨、下跌、平盘、成交、涨停和跌停。短线情绪横截面把市场宽度、封板成功、昨日强势股反馈、接力成功和涨跌停强弱并排展示；任何单项都不单独代表整体判断。[复盘总览截图](../new_screenshots/REV-01.png)一张就能覆盖日期、广度、情绪与盘面事实。

实现上由交易日服务统一样本，pandas 计算横截面与历史窗口，前端展示比例条、指标卡和“样本不足”的状态。

<a id="market"></a>
## 02 · 盘面数据

A 股指数、隔夜外围与重点美股各在自己的交易日期下展示。用户先看背景，再回到 A 股涨跌家数、成交额和情绪，不把隔夜外盘数字算入 A 股当日统计。[盘面数据截图](../new_screenshots/REV-02.png)集中呈现分市场卡片；后端负责规范化来源与日期。

<a id="first"></a>
## 03 · 首板分析

首板按首次封板时间排列，同时保留行业、开板次数、成交、换手与流通市值。它帮助识别新出现的方向，也提供单股入口继续到[个股研究](功能索引.md#value)。[首板分析截图](../new_screenshots/REV-03.png)同时覆盖排序、封板质量和下钻按钮；数据按交易日与股票代码去重汇总。

<a id="heat"></a>
## 04 · 五日热度

把当天热点放回最近五个交易日，观察题材新增、升温、持续或退潮；龙头与跟随股保留不同角色，再回到当日涨停和连板样本。[五日热度截图](../new_screenshots/REV-04.png)对应趋势与分组卡。历史快照按日保存，不用最新值覆盖过去。

<a id="sample"></a>
## 05 · 涨停样本统计

先解释统计对象和排除项，再看行业、题材、板位、封板时间与次日表现。页面允许切换当日或历史窗口，结果旁显示样本分母，避免把“只有少数股票有字段”写成全市场结论。[样本总览](../new_screenshots/REV-05.png)和[封板时间、次日表现局部图](../new_screenshots/REV-05-b.png)互补，后一张突出细节。分组计算和口径说明由后端一并返回。

<a id="ladder"></a>
## 06 · 连板天梯

首板、二板及以上按板位形成梯队；最高高度之外，还要看晋级、断层、封板质量和昨日连板的隔日反馈。监管异动、N 天 M 板与明日触发线用文字标签说明，颜色只作辅助。工作台保留快捷卡和“完整天梯”入口，完整结构在这里阅读。[连板天梯截图](../new_screenshots/REV-06.png)。

<a id="cycle"></a>
## 07 · 情绪周期

将当日市场宽度、封板成功和亏钱效应放进固定历史窗口，区分统计位置与主观体感；同时展示与上一交易日相比的改善或恶化。样本少、缺失或口径变化时降低解释强度。[情绪周期截图](../new_screenshots/REV-07.png)对应阶段、分位和风险说明。

<a id="tomorrow"></a>
## 08 · 明日验证

在盘后保存**观察对象、指标、方向、阈值、核对时间与失效条件**。页面把“我预期什么”与“实际发生什么”分开，保留创建日和核对日；以后不能悄悄改写昨天的判断。[明日验证截图](../new_screenshots/REV-08.png)。条件以版本化记录保存，下一交易日由时点任务匹配；也可从[工作台盘后](工作台.md#after)进入。

<a id="auction"></a>
## 09 · 竞价核验

竞价核验把已保存的条件与 09:15、09:20、09:24:30、09:24:50、09:25 的实际采集结果并列。价格、样本范围、来源时间和采集状态分别记录；缺失不是 0，也不能拿 09:35 的盘中快照补写 09:25。当前历史日期仍缺完整可验证的 09:25 真实快照，**下一交易日真盘验收前不提供成功结论**。[竞价页界面截图](../new_screenshots/REV-09.png)仅展示布局与状态，不代表数据已通过验收。[回看工作台竞价说明](工作台.md#auction)。

<a id="evidence"></a>
## 10 · 口径与证据

这里集中解释交易日、市场范围、样本分母、字段来源和失败记录。读者可以从图表返回原始事实，知道哪些结论可核对、哪些暂缺或不适用。[口径与证据截图](../new_screenshots/REV-10.png)。数据层保留来源与时间；前端用文字状态区分完整、部分和缺失。

复盘得出的对象可进入[板块中心](功能索引.md#plates)、[指标机器人](指标机器人.md)和[个股研究](功能索引.md#value)；若要把复盘事实交给模型解释，见[AI 助手的复盘分支](AI助手.md#review)。
