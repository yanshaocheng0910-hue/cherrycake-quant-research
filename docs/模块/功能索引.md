## 市场观察

<a id="plates"></a>
### 板块中心

从行业、概念和指数看市场结构：先比较涨跌与广度，再查看资金快照、历史趋势和成分股，最后进入[单股机器人](指标机器人.md)。资金方向、成分数量、日期和来源分开显示，避免把板块热度直接说成个股信号。技术上由板块主数据、行情与成分关系接入 FastAPI，pandas 做分组统计，ECharts 绘制趋势与热力图。图位：[行业与概念板块](../new_screenshots/SHOT-012-a.png) · [跨模块入口局部](../new_screenshots/SHOT-012-b.png)。

[阅读板块、排行、异动和 QQQ 的完整章节](市场发现.md)

### 排行榜

按涨幅、成交、估值、板块表现或机器人状态发现候选，再从一行结果进入详情。排序帮助“先看谁”，不代替研究结论；用户仍需核对行情时间与风险。技术上由统一的候选字段和筛选状态驱动前端排序。[多维排行榜截图](../new_screenshots/SHOT-016.png)。

<a id="alerts"></a>
### 异动中心

按标的、周期和阶段回看候选、确认、保持、撤回等信号事件。普通账号与站长共享扫描池隔离；单股可从[机器人](指标机器人.md)继续查看当时的 K 线与触发原因。后端存储事件时间和信号状态，页面提供筛选与历史下钻。[异动信号截图](../new_screenshots/SHOT-026.png)。

### QQQ 与海外指数研究

把海外指数/代理数据作为独立观察对象：展示价格、周期、指标和数据源边界，不把代理关系伪装成真实标的成分。可从[机器人](指标机器人.md)的周期与信号说明继续理解。图位：[QQQ 判断区](../new_screenshots/SHOT-009-a.png)；图表中包含内部策略细节，公开截图暂不放出。

## 信号与研究

<a id="screener"></a>
### 智能选股

经典策略提供可重复的条件起点；口语描述由[AI 解析](AI助手.md#screener)转成候选条件，再经过字段白名单、歧义提示、用户确认和确定性扫描。结果显示命中条件和未覆盖的字段，供继续进入[机器人](指标机器人.md)或[回测](#validation)。前端把“描述—复核—扫描”分层，FastAPI 负责解析路由和条件验证。[条件与自然语言截图](../new_screenshots/SHOT-018.png)。

[阅读选股、个股研究、PEG 与历史研究的完整章节](选股与个股研究.md)

<a id="value"></a>
### 个股研究与估值

个股研究把业务、行业、财务、现金流、技术位置、公告催化和反方风险分开，输出可回看的研究记录。复杂问题通过[阶段 Agent](AI助手.md#research)推进；行情和公告先封存成事实，结论能返回来源与缺口。[深度研究截图](../new_screenshots/SHOT-030-b.png)。

PEG 把现价、预期收益和增长放到同一页核对，重点是**字段是否齐全、来源是否一致、这种比较是否适用**。没有通过校验的一致预期 EPS 就不计算前瞻 PE，也不凭普通说明表或研报标题补数。[PEG 结果](../new_screenshots/SHOT-034-a.png) · [数据质量与增长依据](../new_screenshots/SHOT-034-b.png)。技术上字段校验、数值计算和缺失状态与 AI 解释分离。

### 历史研究

研究命题、规则确认、盲测与实际记录用于把“我当时怎么想”与“后来发生了什么”分开保存。资料和统计支持回看，却不把历史拟合说成未来保证。更细的入口可从[动态产品](https://cherrycake.cc/login)按账号可用范围查看；[历史研究总览图](../new_screenshots/OVERVIEW-HISTORY.png)。

## 资讯与研报

<a id="information"></a>
### 市场简报、资讯雷达与实时动态

市场简报把当天重要事实压缩成一页，并保留事实日期和来源；资讯雷达按主题、标的、来源和时间筛选，重要条目可回到原文；实时动态强调“何时更新、现在是否仍新鲜”。这三者是研究资料入口，不直接生成交易信号。后端做来源规范化与索引，前端按时间和状态筛选。[市场简报截图](../new_screenshots/SHOT-036.png)。

[阅读六个资讯与研报入口的完整章节](资讯与研报.md)

### 产业信号与资讯榜单

产业信号把 GPU、台系月营收、DRAM/商品趋势等资料按行业、日期和来源分开看；第三方授权或字段覆盖不足时明确显示，不能凭一条新闻补成连续数据。资讯榜单提供热度入口，仍需进入来源与标的研究核对。技术上不同来源使用独立适配与状态说明，不把热度当成量化评分。相关页面图位在[原截图清单](../截图清单.md)继续维护。

### 研报中心

按标题、公司、行业、日期与来源找研报；阅读时区分 PDF 原文、提取正文和可定位页码。AI 可以基于有来源的段落解释与比较，但不能把摘要脱离原文。[研报 AI 说明](AI助手.md#documents)。文件读取、文本抽取和页码引用由不同层处理，失败时保留可读状态。图位在[截图清单](../截图清单.md)中预留。

## 自选与验证

<a id="validation"></a>
### 自选与持仓星标

当前注册账号可独立添加、删除自己的自选股并标记持仓；站长、用户 A、用户 B 的清单隔离。持仓星标是个人整理，**不等于后台自动提醒**。用户可从自选进入[机器人](指标机器人.md)或[工作台](工作台.md)。SQLAlchemy/SQLite 保存账号归属，服务端每次以会话身份限定读写。[自选页图](../new_screenshots/SHOT-049.png)展示个人列表与策略入口。

[阅读自选、模拟、回测、信号质量与数据状态的完整章节](验证与账户.md)

### 模拟交易

使用虚拟资金记录账户、订单、持仓与盈亏，用于练习研究到执行的记录过程；与真实交易接口完全隔离。账号权限和当前开放范围由网站控制，不把展示截图当作所有用户均可下单的承诺。[模拟页面图](../new_screenshots/SHOT-052.png)。

### 回测中心

先选标的、周期、日期与信号模式，再对照收益曲线、逐笔成交、成本、滑点和数据覆盖。正式信号、候选信号与生命周期风控采用不同口径；回测按当时可见数据重建，不把未形成的下一根 K 线拿来给过去的决策。后端用 pandas/NumPy 处理时间序列和执行假设，前端以 ECharts 显示曲线与逐笔证据。[回测结果](../new_screenshots/SHOT-055-a.png) · [同期曲线和交易明细](../new_screenshots/SHOT-055-b.png)。

### 信号质量

汇总信号样本量、未来若干 K 线表现、无条件基准和逐条事件；样本少或数据缺失时降低解释力度，不用胜率代替风险。[质量统计](../new_screenshots/SHOT-059-a.png) · [逐条事件](../new_screenshots/SHOT-059-b.png)。

## 平台与数据源

<a id="platform"></a>
### 数据源状态与账号权限

用户可以看行情、历史补充、资讯和模型在当前时刻的可用状态，区别“节点在线”与“所需字段已取得”。失败说明指向具体节点、字段、时段或授权边界。站长提供的模型、个人 API 和当前电脑 WorkBuddy 互不混用；普通账号不读站长的密钥、文件或共享扫描数据。公开版不展示内部 Provider 诊断卡；见[AI 授权](AI助手.md#models)。

网站由 Windows 本机服务运行，通过 Cloudflare Tunnel 接入公网；Cloudflare 不是动态服务本身。公开展示仓库不收录私人项目代码、配置、数据库、会话和日志。更完整的技术链路见[系统架构与数据链路](../系统架构与数据链路.md)。
