# 工作台｜沿交易日组织研究

[返回作品导览](../作品导览.md) · [进入复盘中心](复盘中心.md) · [了解 AI 助手](AI助手.md)

工作台是产品的日常入口，不是一张把所有指标堆在一起的报表。它把**盘前、竞价、盘中、盘后**设为四个一级阶段：先知道现在该核对什么，再按需要进入板块、单股、资讯或验证页面。市场背景、自选、核心股、事件和数据状态贯穿四阶段，但每一阶段关注的问题不同。

| 阶段 | 先回答什么 | 主要分支 | 下一步 |
| --- | --- | --- | --- |
| [盘前](#pre) | 昨日留下哪些条件，隔夜又发生了什么？ | 要点、自选、公告、全球与政策、市场宽度 | 带着问题进入竞价 |
| [竞价](#auction) | 开盘前的真实采集能否支持昨日判断？ | 五时点、范围、自选、板块映射、失败状态 | 只在样本合格时做强弱核验 |
| [盘中](#intraday) | 变化发生在市场、板块还是个股？ | 指数成交、热力图、板块轮动、核心股、事件 | 下钻[板块](功能索引.md#plates)与[机器人](指标机器人.md) |
| [盘后](#after) | 哪些事实值得写成明日可检查的条件？ | 涨跌停、短线情绪、板块落盘、事件归档 | 进入[复盘](复盘中心.md)与[明日验证](复盘中心.md#tomorrow) |

<a id="pre"></a>
## 盘前｜先完成开盘前核对

盘前把上一交易日的事实和隔夜信息整理成阅读顺序。**盘前要点**汇总市场宽度、成交和风险；**自选相关**只取当前账号的清单；**公司公告**保留发布时间与原文入口；**全球与政策**是背景，不被直接解释为买卖信号；**数据状态**告诉用户哪些值来自实时、缓存、历史或暂缺。

第二组盘前卡片看市场结构：主要指数与成交预览、行业内部上涨比例、资金集中方向及历史位置。它们合在一起回答“今天更可能普涨、分化还是收缩”，并把板块代码与观察窗口带到[板块中心](功能索引.md#plates)。后端用 FastAPI 聚合摘要、用 pandas 对齐交易日；前端用更新时间、来源标签和 ECharts 图形区分预览与正式行情。

图位：[盘前要点与关注标的](../new_screenshots/WB-PRE-01.png)。市场宽度与资金预览的公开版截图待补，避免把内部计算参数随截图放出。

<a id="auction"></a>
## 竞价｜把昨日条件交给真实开盘前数据

竞价卡先显示**09:15、09:20、09:24:30、09:24:50、09:25** 的实际采集状态，再看样本范围、证券与板块映射、自选反馈和昨日已保存的验证条件。未采、部分采集与合格样本分开呈现；失败不是 0，未来时间的快照也不能冒充当时价格。

历史日期仍缺可核验的完整 09:25 样本。前一轮修复已经加入独立盘口时间检查，但**下一真实交易日尚未验收**；这里不展示“竞价强弱已判断”的截图。待验收后再补工作台竞价图位，并与[复盘中心的竞价核验](复盘中心.md#auction)共用证据说明。技术上由交易日时点任务采集，后端返回来源、观察时间、范围和错误，页面只对已验证字段计算反馈。

<a id="intraday"></a>
## 盘中｜实时市场与板块轮动

盘中先看指数、成交、涨跌宽度和更新时间，再看行业强弱、资金方向与题材热度。**市场热力图**定位活跃区域；**板块轮动**比较当下与昨日落盘；**事件流和电报**保留来源与发生时间。资金净流入是观察量，不直接等于上涨质量。

进一步下钻到核心股和连板结构：工作台快捷卡展示首板、二板以上梯队、晋级和断层；监管异动、N 天 M 板等特殊情况用文字标签说明；完整列表由[复盘中心的连板天梯](复盘中心.md#ladder)承接。前端 ECharts 负责热力图，后端按统一交易日聚合板块、成分股和事件；从板块到成分股再到[机器人](指标机器人.md)保持同一个标的上下文。

图位：[盘中市场与事件](../new_screenshots/WB-INTRA-01.png) · [板块轮动和热力图](../new_screenshots/WB-INTRA-02.png) · [连板天梯与涨停热力图](../new_screenshots/WB-INTRA-03.png)。最后一组另有[局部补图 A](../new_screenshots/WB-INTRA-03-b.png)和[局部补图 B](../new_screenshots/WB-INTRA-03-c.png)，用来突出梯队与热力图，不把整页缩到看不清。

<a id="after"></a>
## 盘后｜从事实回收走向明日验证

盘后整理涨停、炸板、跌停、封板成功、昨日强势股反馈和板块落盘。事件按交易日归档，结果带有计算完成时间和缺失说明。随后把判断写成**对象、指标、方向、阈值和核对时间**，并同时写明什么情况会让判断失效。

从这里可以打开[复盘看板](复盘中心.md#dashboard)看完整横截面、打开[选股器](功能索引.md#screener)复用条件，或者让[AI 助手](AI助手.md#workbench)解释已显示的事实。次日再回到[竞价核验](复盘中心.md#auction)，形成跨交易日闭环。技术上，盘后样本锁定交易日；验证条件持久化，AI 只接收当前问题需要的事实包，不复制整页 HTML。

图位：[行业涨停结构局部](../new_screenshots/WB-POST-01-b.png) · [复盘中心的盘后情绪](../new_screenshots/REV-01.png)。**明日验证与研究入口**暂留图位，待下一交易日的真实核验一起补齐。

## 公共组件｜个性化布局与状态

用户可以显示、隐藏常用卡片并恢复默认；快捷入口只负责进入机器人、复盘、选股和回测，不另造一套分析结果。自选按账号隔离，普通用户的持仓星标用于个人整理，暂不宣称已接入后台自动提醒。每块数据都显示来源、时间和可用状态；统一猫咪助手沿用当前页面与账号的权限。

图位：[自定义布局与快捷入口](../new_screenshots/WB-COMMON-01-a.png) · [页内助手](../new_screenshots/WB-COMMON-01-b.png)。相关技术：账号偏好持久化、前端组件状态协议、统一路由与页面上下文。
