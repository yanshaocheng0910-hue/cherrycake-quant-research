# 市场发现｜从整体盘面找到值得研究的对象

[作品首页](../../README.md) · [工作台](工作台.md) · [复盘中心](复盘中心.md) · [进入选股与个股研究](选股与个股研究.md)

打开市场页面时，先确认“今天市场有没有形成方向”，再决定“哪只股票值得继续看”。这个领域把 **板块中心、排行榜、异动中心与 QQQ 海外观察** 放在一起：它们都负责发现对象，但回答的问题不同。板块看群体，排行看当下候选，异动看信号变化，海外观察提供独立背景。四者不会替用户直接下结论，发现后仍要进入[指标机器人](指标机器人.md)和[个股研究](选股与个股研究.md#stock-research)核对。

| 入口 | 先看什么 | 继续到哪里 |
| --- | --- | --- |
| [板块中心](#plates) | 行业/概念广度、资金、成分与轮动 | 成分股 → 机器人 |
| [排行榜](#ranking) | 涨幅、成交、估值与信号候选 | 单股研究或加入自选 |
| [异动中心](#alerts) | 候选、确认、保持、撤回的变化 | 逐 K 证据与质量统计 |
| [QQQ 海外观察](#qqq) | 海外指数/代理行情的独立状态 | 周期与来源核对 |

<a id="plates"></a>
## 板块中心｜看的是一组股票，而非一个涨幅

行业和概念先按涨跌、上涨家数与资金方向比较，随后可以切到趋势、热度和成分。一个板块“资金流入”不等于每只成分股都具备买入条件；页面把日期、样本量、板块类型与资金口径留在图旁，避免把不同来源的数字拼成一条假趋势。

使用时先选行业或概念，再看资金快照和历史变化，最后打开成分股列表。若只是个别大市值股票撑起板块表现，可以回到[复盘中心的盘面数据](复盘中心.md#market)看全市场背景，再到[机器人](指标机器人.md)看单股。板块主数据与成分关系由后端对齐，pandas 做分组统计，ECharts 表现资金与热度。

<a id="ranking"></a>
## 排行榜｜把“先研究谁”变成可操作的入口

排行榜可在涨幅、跌幅、成交、量比、换手及机器人状态之间切换，也可按市场和板块收窄范围。它给出候选顺序，用户点击股票后带着代码进入图表、自选或异动详情。行情更新时间与数据来源仍留在页面上；“排名第一”不等于信号已确认。

实现上，后端把行情与可用信号整理成统一字段，前端保持筛选条件、排序方向与跳转上下文。信号尚未扫描或 OpenD 受限时显示状态，不用旧缓存补成实时排行。

![排行榜：多维筛选与单股入口](../new_screenshots/SHOT-016.png)

<a id="alerts"></a>
## 异动中心｜看信号从出现到结束

异动页把标的、周期、方向、触发时间和生命周期放在一起。用户可从“全部监控”收窄到持仓、自选或某一周期，再筛选候选、确认、保持与结束等阶段。需要解释某次变化时回到[机器人逐 K 快照](指标机器人.md#signal)，需要判断同类信号历史表现时进入[信号质量](验证与账户.md#quality)。

信号事件按标的、周期与时间记录，页面显示筛选和来源；共享扫描结果与个人自选、个人持仓分别受账号权限约束。异动不自动生成真实交易订单。

![异动中心：条件、周期与状态筛选](../new_screenshots/SHOT-026.png)

<a id="qqq"></a>
## QQQ 海外观察｜保持代理关系透明

QQQ 决策台用海外行情与多周期证据观察纳斯达克相关方向。页面把所选交易对象、数据市场、最近交易日与代理关系分开说明；美股前一交易日不能被当作 A 股当天的实时价格。用户可阅读当前判断、风险与逐 K 证据，但不把这一页当作自动下单器。

截图只展示判断区；涉及内部策略配方的图表没有上传。数据接入和时间对齐由后端完成，页面主要负责呈现可核对的来源与状态。
