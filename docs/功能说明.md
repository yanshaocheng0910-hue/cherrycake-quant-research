## 一、工作台

### 功能是什么

工作台是日常打开的平台首页。它把市场总览、自选与持仓、板块和指数、市场热度、快捷研究入口以及数据状态放在一个入口中。它不替代下游研究页，而是先回答“今天应该先看什么”。

### 使用效果

- 先建立市场背景，再进入单股或单一资讯，减少只盯一只股票的偏差。

### 工程实现要点

### 指标怎样配合

页面将多个指标家族分别作为不同观察角度：趋势类回答方向和背景，动量类回答变化速度，资金与成交类回答参与度，结构类回答位置和形态。系统先整理出基础方向，再以分层方式汇总证据强度，随后把多周期状态和风险门槛作为额外上下文。

用户阅读时建议按这个顺序：

1. 先看当前周期和数据更新时间，确认自己看到的是什么时点。
2. 看趋势、动量、资金和结构是否同向，先识别冲突，不急着看总分。
3. 看评分处于候选、确认、保持还是观望等状态，并查看支持项和拦截项。
4. 按场景使用人工过滤：顺势、突破、回踩或震荡时，确认要求可以不同。
5. 回到关键价位和逐 K 快照，确认风险边界和触发原因。

### 使用效果

- 把“这只股票现在怎么样”拆成趋势、结构、资金和风险四个可读维度。
- 让评分回到证据和状态，而不是只显示一个没有解释的买卖标签。
- 支撑、阻力、止损和数据来源分开表达，便于形成风险计划。
- 同一组信号语义可以继续被异动中心、回测中心和质量统计使用。

### 工程实现要点

Python 指标计算层输出结构化指标与信号快照，FastAPI 提供数据，ECharts 绘制 K 线和指标，前端承载人工确认开关。公开说明只讲阅读逻辑，不泄露内部公式、权重、阈值和策略配方。
