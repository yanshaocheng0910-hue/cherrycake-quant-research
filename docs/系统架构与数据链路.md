## 总体结构

```text
行情与资讯源
    ↓
数据接入与来源标记
    ↓
事实整理、缓存、历史回补
    ↓
指标引擎 / 复盘计算 / 估值 / 策略 / 回测
    ↓
FastAPI 服务与研究任务
    ↓
HTML + CSS + JavaScript + ECharts 工作台
    ↓
用户查看、筛选、验证和追问
```

## 数据链路

### 1. 数据接入

实时行情主要通过 Futu OpenD 获取；历史资料与交易日回补按具体页面接入能力选择来源。Baostock 目前属于历史补充与形态扫描的评估路径，不写成现行网站的生产数据源。资讯、公告、研报和产业数据按各自来源进入[资讯与研报入口](../README.md#chapter-21)。

### 2. 事实整理

进入业务层的数据带有来源、时间、标的、周期和数据状态。页面先展示可追溯的事实，再由指标、复盘或估值模块计算派生结果。

### 3. 研究计算

- [指标引擎](../README.md#chapter-07)计算多周期指标、信号和评分
- [复盘模块](../README.md#chapter-10)计算涨停、炸板、连板、情绪和次日验证
- [策略选股](../README.md#chapter-16)执行经过审核的结构化条件
- [回测模块](../README.md#chapter-29)在固定日期窗口重建可见数据和交易过程
- [PEG 估值](../README.md#chapter-20)检查输入字段、适用性和缺失项

### 4. 服务编排

FastAPI 将这些能力提供给前端页面。需要较长时间的[回测](../README.md#chapter-29)、[研报解析](../README.md#chapter-26)和 [AI 研究](../README.md#chapter-06)使用任务化接口，前端显示进度并读取最终结果。

### 5. 页面呈现

JavaScript 请求 API 后更新页面；ECharts 将结构化结果绘制成 K 线、折线图、柱状图、热力图和统计图。页面同时保留来源、事实日期和数据覆盖信息。

## 页面之间如何协作

```text
看盘工作台
    ├── 点击股票 → 指标机器人
    ├── 点击板块 → 板块与指数中心
    ├── 点击信号 → 异动中心
    └── 点击资讯 → 资讯中心

策略选股
    ├── 候选解释 → 指标机器人
    └── 综合评分回测 → 回测中心

A 股复盘中心
    ├── 首板 / 连板 → 个股研究
    ├── 明日条件 → 竞价核验
    └── 研究事实 → AI 研判
```

## 实时、缓存与回补

系统不是简单地判断“连接成功或失败”，而是按具体能力确认：实时报价可用不代表财务字段可用，节点在线也不代表所有请求都能返回。

当实时路径不可用时，系统可以读取已保存的行情或历史回补；每条结果都应该保留来源和时效。无法保证口径时，显示不可用或受限状态，不用旧数据伪装成实时数据。

## AI 数据边界

AI 研判前先从平台读取与问题相关的结构化事实，再进行有界投影。模型回答需要和原始事实分开显示，事实日期、来源和缺失项不能因为模型生成文字而消失。

AI 路径分为：

- 普通单轮问答
- 事实扫描或预取
- 完整研究任务

这三类任务的工具范围、输入规模和结果状态不同，避免用一段普通回答冒充完整研究流程。

## 当前公网链路

```text
浏览器
  ↓ HTTPS
Cloudflare Tunnel（固定域名）
  ↓
Windows 本机 Uvicorn / FastAPI（127.0.0.1:9000）
  ├── SQLite / SQLAlchemy
  ├── Futu OpenD（独立运行条件）
  └── 研究任务与缓存
```

这条链路依赖电脑开机、本机应用和 Tunnel 持续运行。Cloudflare 不会在电脑关机后继续运行动态网站，也不会替本机提供行情或私有 AI 模型。

## 后续服务器迁移方向

```text
浏览器
  ↓ HTTPS
nginx / 反向代理
  ↓
Uvicorn
  ↓
FastAPI
  ├── SQLite / SQLAlchemy
  ├── Futu OpenD
  ├── 已授权且经过验证的历史与资讯源
  └── 研究任务与缓存
```

上面的 nginx / systemd 是未来使用境外 Linux 服务器时的部署方向，不表示已经投入运行。静态展示材料可以单独发布到 GitHub 或 Cloudflare Pages；动态业务服务始终需要实际运行的应用、数据库和数据源节点。
