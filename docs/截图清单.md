# 截图清单与放图位置

截图用于项目展示和后续用户教学。请把真实图片放进仓库根目录的 `screenshots/` 文件夹，并严格使用下面的文件名。展览页会自动寻找同名 PNG 或 WebP；文件不存在时显示“待补真实截图”占位。

## 放图规则

- 一张图尽量只表达一个功能或一个状态。
- 桌面端建议保留完整页面宽度；需要展示响应式能力时另存约 390px 宽的移动端图。
- 截图中不要出现 API Key、密码、邮箱验证码、服务器 IP、Cookie、内部账号和未授权数据。
- 截图文件只放产品界面，不复制主项目源码、数据库或工作日志。
- 如需新增截图，先在 `script.js`、本清单和 `docs/功能说明.md` 中保持同名，再放入图片。
