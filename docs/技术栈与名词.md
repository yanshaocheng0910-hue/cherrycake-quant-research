# 技术栈与专业名词

[返回产品全览](../README.md#chapter-01) · [技术如何落到功能](../README.md#chapter-03) · [系统架构与数据链路](系统架构与数据链路.md)

## 1. 前端技术

### HTML

HTML 负责页面的结构，例如导航栏、搜索框、表格、卡片、K 线区域和结果面板。它决定浏览器“页面上有什么”。

### CSS

CSS 负责视觉表现，包括颜色、间距、字体、响应式布局、浅色主题和移动端适配。工作台和研究页面使用统一的视觉语义，让上涨、下跌、风险、支撑和阻力能够快速区分。

### JavaScript

JavaScript 负责页面行为，例如搜索联想、周期切换、筛选条件、异步加载、弹窗、图表更新和任务进度。

### ECharts

ECharts 是前端图表库，用于绘制 K 线、均线、指标叠加、资金曲线、收益曲线、热力图和统计图。它让后端返回的数据可以变成可交互的视觉结果。

### 响应式布局

响应式布局让同一个页面适应电脑和手机屏幕。展示图可以同时准备 1440px 桌面图和 390px 手机图，说明页面不是只为一个固定尺寸制作。

## 2. 后端技术

### Python

Python 用于行情处理、指标计算、策略逻辑、研究任务和服务端接口。量化项目中的数据清洗、时间序列计算和自动化任务都集中在这一层。

### FastAPI

FastAPI 是 Python Web 框架。它把后端能力组织成 HTTP 接口，例如读取某只股票 K 线、运行回测、保存策略、查询资讯和创建 AI 研究任务。

### Uvicorn

Uvicorn 是 Python 的 ASGI 应用服务器，负责把 FastAPI 应用真正跑起来，并处理浏览器或前端发来的请求。

### API

API 是前端和后端之间约定好的通信入口。前端请求“某只股票的日线数据”，后端返回结构化 JSON；前端再把 JSON 渲染成卡片、表格和图表。

### 异步任务

回测、研报解析和 AI 研究可能需要较长时间，因此不让浏览器一直等待一个请求，而是创建任务、显示进度，再读取任务结果。这种方式也便于取消、恢复和记录证据。

## 3. 数据与存储

### Futu OpenD

Futu OpenD 是行情接入服务，平台通过它读取 A 股、港股、美股、ETF 等标的的报价和多周期 K 线。页面会披露当前行情来源和时间。

### baostock

Baostock 是正在评估的历史补充与形态扫描数据路径，不等同于实时行情源，也不表示当前网站已经把它接为生产数据源。页面的实际来源与时效以[数据源状态](../README.md#chapter-31)为准。

### SQLAlchemy

SQLAlchemy 是 Python 的数据库访问工具。它把股票、行情、研究任务、策略和账号等数据映射为可维护的业务对象，避免所有逻辑都直接拼接 SQL。

### SQLite

SQLite 是轻量级关系数据库，适合单机或小规模部署保存平台状态、行情事实和研究记录。展示页面中的数据库图标指的是这类持久化层，不是把数据库暴露给浏览器。

### 缓存

缓存是对短时间内不变结果的临时复用。它可以减少重复请求和等待，但缓存命中不代表数据仍然是实时数据，所以页面需要同时显示来源和更新时间。

### 数据降级

当实时节点不可用时，系统按照能力选择本地持久化数据、历史回补或明确的不可用状态。降级的重点是诚实说明数据时效，不用旧数据冒充实时数据。

## 4. 量化研究名词

### K 线

K 线用开盘价、最高价、最低价和收盘价描述一个时间周期内的价格变化。1 分钟、日线、周线等只是时间粒度不同。

### 多周期

同一只股票同时从分钟、小时、日线、周线等时间尺度观察。短周期适合看盘中变化，大周期适合观察趋势背景。

### DK / DKX / MACD / O 粒势带

这些是平台使用的指标和指标组合。展示时重点说明它们怎样参与趋势、动量、结构和风险判断，不把指标名称本身当成结论。

### 四维评分

平台把结果拆成趋势、结构、资金和风险四个维度。它的作用是让用户知道总分由哪些部分组成，而不是只给一个无法解释的数字。

### 信号生命周期

一个信号可能经历候选、确认、保持、撤回和结束。记录生命周期可以避免把历史上短暂出现的信号误写成一直有效。

### 多周期共振

当同一组周期出现同方向信号时，平台将其作为额外证据；跨组周期则单独提示，不把不同时间尺度简单相加。

### 回测

回测使用历史行情重放策略规则，观察在过去某个时间窗口内可能发生的交易和结果。回测不是未来收益承诺，关键是明确数据窗口、执行假设、交易成本和未平仓状态。

### 最大回撤

最大回撤表示从某个历史高点到之后低点的最大下跌幅度，用来描述策略经历过的最差阶段，而不只看最终收益。

### PEG

PEG 常用市盈率除以盈利增长率，用于辅助估值比较。增长率为负、字段缺失或来源不完整时，页面会显示不适用或缺失，不强行给出结论。

### As-of

As-of 表示“截至某个时点可见的数据”。回测和历史研究使用这个概念避免把未来才知道的信息倒灌到过去。

## 5. AI 与权限名词

### BYOK

BYOK 是 Bring Your Own Key，意思是用户使用自己的模型 API Key。用户自己的模型额度和站长共享模型额度必须分开。

### Agent

Agent 是能按步骤调用工具、读取事实并完成任务的模型工作流。平台中的 Agent 用于只读研究，不拥有下单能力。

### 事实投影

事实投影是把页面需要的结构化事实，按当前问题筛选成模型真正需要看到的一部分。这样可以减少无关上下文，也避免把整库数据直接发送给模型。

### 结果缓存

结果缓存是平台保存并复用相同问题和相同事实下的回答。它与模型供应商的提示词缓存不是一回事，页面应分别描述。

### 权限隔离

权限隔离意味着客户只能使用自己拥有的模型路径和数据范围；站长的密钥、本机 CLI 登录态和内部配置不会因为客户打开了 AI 页面就自动共享。

## 6. 部署与工程名词

### nginx

nginx 是反向代理和 Web 服务器。它可以接收 HTTPS 请求，再把请求转给后端应用，同时处理静态文件、域名和基础访问控制。

### systemd

systemd 是 Linux 的服务管理器。它负责应用开机启动、进程退出后的拉起和运行状态管理。

### HTTPS

HTTPS 对浏览器和服务器之间的通信进行加密，保护登录信息、请求参数和结果传输。

### Cloudflare Pages / Tunnel

Cloudflare Pages 适合发布静态展示页；Cloudflare Tunnel 可以把正在运行的本地服务接入固定域名。它们是发布或接入层，不等于一台会在电脑关机后继续运行的动态服务器。
