# 产品宣传页

这是主项目当前宣传页的独立静态副本，完整保留产品宣传内容和配套素材：

- 指标体系与四层指标说明
- 机器人简化模式、专业证据和受控流程
- 市场发现、板块中心、策略选股和同窗回测
- AI 助手、事实依据和研究闭环
- 首屏 K 线动效、轮播交互和响应式布局

此副本恢复了主项目备案期间用 `<template>` 暂时隐藏的宣传区块，因此在展示仓库中可以完整浏览。登录、注册和动态业务链接已改为返回展示仓库的功能说明区，静态仓库本身不承载动态登录或实时行情。

资源全部使用当前目录下的相对路径，宣传页可以直接在 GitHub Pages、Cloudflare Pages 或本地静态服务器中发布。
